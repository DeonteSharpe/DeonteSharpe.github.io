# Project reflection

## What Went Well

> Building the website went well because I was able to see my progress visually as I added new plugin features. Watching the website come together made it easier to understand how HTML works and helped me stay motivated throughout the project.

## What Went Wrong

> The biggest challenge was styling the website. It took some trial and error to get the design looking the way I wanted, and I spent time researching different CSS properties and techniques to achieve the layout and color scheme I envisioned.

## What I Would Do Differently

> If I were to complete this project again, I would first create a simple layout or draft of the website before beginning the styling process. Planning the structure and design ahead of time would make development more organized and reduce the amount of trial and error needed.
